# Videorix

Videorix — локальное приложение для загрузки видео с YouTube. Вставьте ссылку, выберите
доступное разрешение и сохраните результат в MP4 или MOV.

Готовые приложения для macOS и Windows работают без Docker, Node.js, Python и отдельно
установленного FFmpeg. Интерфейс и данные доступны только на текущем компьютере. Готовый файл
можно скачать повторно, пока он не удалён вручную или автоматически через час.

> Используйте Videorix только для материалов, которые вам разрешено скачивать и использовать.
> Проект не обходит DRM, платный доступ или ограничения правообладателей и не связан с YouTube
> или Google.

## Возможности

- выбор точного доступного разрешения;
- сохранение в MP4 или MOV без перекодирования видео;
- объединение видео и звука через встроенный FFmpeg;
- последовательная очередь из нескольких загрузок;
- повторное скачивание готового файла в течение 60 минут;
- ручное удаление отдельных файлов и общая очистка очереди;
- контроль свободного места и автоматическая очистка временных данных;
- гостевой режим и локальный вход в YouTube, когда сервис требует авторизацию;
- встроенные yt-dlp, FFmpeg и FFprobe в desktop-сборках;
- сохранение локальной YouTube-сессии между перезапусками.

## Простая установка без Docker

Откройте страницу [последнего релиза](https://github.com/oxo-foxxo/youtube-downloader/releases/latest)
и скачайте файл для своего компьютера:

| Система | Файл |
| --- | --- |
| Mac с Apple Silicon (M1–M5) | `Videorix-…-mac-arm64.dmg` |
| Mac с Intel | `Videorix-…-mac-x64.dmg` |
| Windows 10/11 x64 | `Videorix-…-windows-x64.exe` |

### macOS

1. Откройте `.dmg` и перенесите Videorix в **Applications**.
2. Запустите Videorix.
3. Пока сборка не подписана Apple Developer ID, macOS может заблокировать первый запуск. Нажмите
   приложение правой кнопкой → **Открыть**, либо разрешите запуск в **Системные настройки →
   Конфиденциальность и безопасность**.

### Windows

1. Запустите скачанный `.exe` и завершите установку.
2. Откройте Videorix через меню «Пуск» или ярлык на рабочем столе.
3. Пока сборка не подписана коммерческим сертификатом, Microsoft Defender SmartScreen может
   показать предупреждение. Выберите **Подробнее → Выполнить в любом случае**.

Подпись не влияет на локальность приложения, но убирает системные предупреждения. Для публичной
массовой дистрибуции рекомендуется подписать macOS и Windows сборки.

## Как скачать видео

1. Откройте Videorix.
2. Вставьте ссылку на обычное видео YouTube или Shorts.
3. Нажмите **Проверить**.
4. Выберите разрешение и MP4 или MOV.
5. Нажмите **Скачать**.
6. Когда файл будет готов, выберите место сохранения. Кнопка **Скачать ещё раз** останется в
   очереди.

Можно добавлять новые ссылки, пока предыдущий файл готовится. Задачи выполняются по одной, чтобы
несколько тяжёлых загрузок не занимали весь диск одновременно.

## Вход в YouTube

Некоторые сети и видео YouTube блокирует проверкой «Войдите, чтобы подтвердить, что вы не бот».
В этом случае:

1. Нажмите **Войти в YouTube**.
2. Videorix откроет отдельное окно установленного Google Chrome, Microsoft Edge или Brave.
3. Самостоятельно войдите в Google и пройдите двухэтапную проверку, если она включена.
4. Вернитесь в Videorix и нажмите **Я вошёл**.
5. Повторите проверку ссылки.

Desktop-версия создаёт отдельный браузерный профиль и не читает профиль вашего обычного браузера.
Cookies YouTube копируются во временный файл только на время вызова yt-dlp и затем удаляются. Они
не передаются другим провайдерам. Кнопка **Выйти** отменяет незавершённые задачи и удаляет отдельный
профиль YouTube.

Для входа должен быть установлен Chrome, Edge или Brave. На Windows Edge уже входит в систему.

## Хранение и очистка

- рабочие данные desktop-версии находятся в `~/Library/Application Support/Videorix` на macOS и
  `%APPDATA%\Videorix` на Windows;
- готовый файл хранится 60 минут и доступен для повторного скачивания;
- **Удалить файл** очищает одну завершённую задачу;
- **Очистить завершённые** удаляет все завершённые файлы;
- уже сохранённый файл остаётся в выбранной пользователем папке;
- прерванные задачи очищаются при перезапуске и автоматически не продолжаются;
- приложение сохраняет резерв 1 ГиБ свободного места.

## Docker Compose — альтернативная установка

Docker-вариант полезен разработчикам, для диагностики и для полностью воспроизводимого окружения с
локальными Cobalt и PO-token провайдерами. Обычному пользователю он не требуется.

### macOS одной командой

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/oxo-foxxo/youtube-downloader/main/install.sh)"
```

### Windows одной командой

```powershell
irm https://raw.githubusercontent.com/oxo-foxxo/youtube-downloader/main/install.ps1 | iex
```

Если Docker Desktop отсутствует, установщик предложит скачать официальный дистрибутив. Условия
Docker пользователь принимает самостоятельно в окне Docker Desktop. После запуска приложение
доступно по адресу **http://localhost:8080**. Повтор команды обновляет Videorix, сохраняя настройки,
сессию и готовые файлы в Docker-томах.

Лицензия Docker Desktop бесплатна для личного использования, образования, некоммерческих open
source проектов и малого бизнеса в пределах условий Docker. Для других организаций проверьте
[условия Docker Desktop](https://docs.docker.com/subscription-billing/desktop-license/).

### Ручная установка Docker-варианта

```bash
git clone https://github.com/oxo-foxxo/youtube-downloader.git
cd youtube-downloader
docker compose up -d --build
```

Проверка состояния:

```bash
docker compose ps
curl http://localhost:8080/health
```

Остановить приложение с сохранением данных:

```bash
docker compose down
```

Удалить контейнеры, очередь и отдельную YouTube-сессию:

```bash
docker compose down -v
```

## Диагностика

| Проблема | Что проверить |
| --- | --- |
| Desktop-приложение не запускается | Разрешите первый запуск неподписанного приложения по инструкции выше. |
| Вход в YouTube не открывается | Установите Chrome, Edge или Brave и повторите вход. |
| YouTube просит подтвердить вход | Используйте отдельное окно входа и временно отключите VPN. |
| Недостаточно места | Очистите завершённые задачи и освободите место на системном диске. |
| Docker-версия не открывается | Проверьте `docker compose ps` и журналы `docker compose logs --tail=200`. |
| Порт 8080 занят в Docker-версии | Скопируйте `.env.example` в `.env` и измените `APP_PORT`. |

Статус `/health` подтверждает доступность компонентов, но не гарантирует, что YouTube не изменил
внутренние механизмы или не ограничил текущее подключение.

## Ограничения

- поддерживаются одиночные опубликованные видео и Shorts;
- плейлисты и прямые трансляции не поддерживаются;
- приватные, платные, возрастные и регионально закрытые материалы могут быть недоступны;
- MOV создаётся через remux без перекодирования и не является ProRes;
- интерфейс предлагает только сочетания разрешения и контейнера без изменения кодеков;
- изменения YouTube могут временно нарушить один или несколько способов загрузки;
- desktop-сборки пока не подписаны сертификатами Apple и Microsoft.

## Архитектура

Desktop-приложение упаковано через Electron. Оно запускает локальный Fastify API только на
`127.0.0.1`, показывает React-интерфейс в изолированном окне и использует вложенные исполняемые
файлы yt-dlp, FFmpeg и FFprobe. Для входа запускается отдельный профиль системного Chrome, Edge или
Brave с локальным управляющим портом и случайным токеном. Профиль и cookies не отправляются на
сервер Videorix.

Docker Compose запускает четыре изолированных сервиса:

- `app` — Fastify API, React-интерфейс, очередь, yt-dlp и FFmpeg;
- `session-browser` — отдельный Chromium с noVNC для входа в YouTube;
- `cobalt` — резервный источник медиапотоков;
- `bgutil` — локальный поставщик PO-токенов для yt-dlp.

Служебные порты Docker-варианта не публикуются на хост.

## Разработка

Нужны Node.js 22+ и pnpm 11:

```bash
pnpm install
pnpm run typecheck
pnpm test
pnpm run format:check
pnpm run build
```

Локальный запуск desktop-версии:

```bash
pnpm run desktop:start
```

Сборка `.dmg` или `.exe` на текущей операционной системе:

```bash
pnpm run desktop:dist
```

GitHub Actions собирает Apple Silicon, Intel macOS и Windows x64 на соответствующих нативных
runner-ах. При создании тега `v*` файлы автоматически прикрепляются к GitHub Release.

E2E-проверки используют локальный тестовый сервер и не обращаются к YouTube:

```bash
pnpm exec playwright install chromium
pnpm run test:e2e
```

Для явной онлайн-проверки уже запущенного Docker-приложения:

```bash
pnpm run smoke:youtube -- "https://www.youtube.com/watch?v=VIDEO_ID" --height 720 --container mp4
```
