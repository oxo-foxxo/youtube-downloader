# YouTube Downloader

Локальный веб-сервис для сохранения публичных завершённых видео YouTube в точном доступном разрешении. Пользователь вставляет ссылку, выбирает качество и получает MP4 или MOV. Видео и звук объединяются через FFmpeg в режиме stream copy без перекодирования.

Сервис использует три способа загрузки по очереди: yt-dlp с PO-токенами, собственный контейнер Cobalt и YouTube.js. Cookies, вход в аккаунт и YouTube Premium не используются.

## Запуск на macOS и Windows

Нужен Docker Desktop с Docker Compose v2. Склонируйте или распакуйте проект, откройте терминал в его каталоге и выполните:

```bash
docker compose up -d --build
```

На Windows эта же команда работает в PowerShell. Первый запуск скачивает и собирает образы и поэтому занимает несколько минут. После прохождения health checks откройте [http://localhost:8080](http://localhost:8080).

Проверка состояния на macOS:

```bash
curl http://localhost:8080/health
```

Проверка состояния в PowerShell:

```powershell
Invoke-RestMethod http://localhost:8080/health
```

Статус `degraded` означает, что один из резервных механизмов временно недоступен. Основной сценарий при этом может продолжать работать.

## Управление

Посмотреть состояние контейнеров и журналы:

```bash
docker compose ps
docker compose logs -f app cobalt bgutil
```

Остановить сервис, сохранив временный том:

```bash
docker compose down
```

Остановить сервис и удалить все оставшиеся подготовленные файлы:

```bash
docker compose down -v
```

Обновить зафиксированные образы и пересобрать приложение после обновления репозитория:

```bash
docker compose pull
docker compose build --pull app
docker compose up -d
```

## Доступ и хранение

По умолчанию порт слушает только `127.0.0.1`, поэтому интерфейс доступен только на этом компьютере. Cobalt и bgutil не публикуют порты на хост.

Чтобы явно открыть интерфейс в локальной сети, скопируйте `.env.example` в `.env`, задайте `APP_BIND_ADDRESS=0.0.0.0` и перезапустите Compose. Используйте этот режим только в доверенной сети: в первой версии нет пользователей, паролей и HTTPS.

Файлы находятся во временном Docker-томе. Одновременно выполняется одна задача. Готовый файл удаляется после успешной передачи браузеру или через 60 минут. При перезапуске незавершённые остатки очищаются.

## Ограничения

- Поддерживаются обычные публичные видео и Shorts, завершившие публикацию.
- Не поддерживаются плейлисты, прямые трансляции, приватные, платные, возрастные и регионально закрытые видео.
- MOV создаётся обычным remux без перекодирования; это не ProRes.
- Доступны только сочетания разрешения и контейнера, которые можно собрать из исходных дорожек без изменения кодеков.
- Изменения внутренних механизмов YouTube могут временно нарушить один или все способы загрузки. Обновляйте зафиксированные версии только после smoke-проверки.

Скачивайте и используйте только материалы, на которые у вас есть необходимые права или разрешение правообладателя.

## Разработка и проверки

Локально нужны Node.js 22+ и pnpm 11:

```bash
pnpm install
pnpm test
pnpm run typecheck
pnpm run build
```

Онлайн-проверка YouTube отделена от детерминированных тестов и требует явно переданной публичной ссылки. Команда описана после добавления smoke-сценария в финальном этапе разработки.

## Компоненты и лицензии

- Приложение использует Fastify, React, YouTube.js, yt-dlp и FFmpeg на условиях их лицензий.
- Cobalt распространяется по AGPL-3.0 и запускается как неизменённый отдельный образ `ghcr.io/imputnet/cobalt:11.7.1-a636575`.
- `bgutil-ytdlp-pot-provider` распространяется по GPL-3.0 и запускается отдельным образом версии 2.0.1.
- `yt-dlp-getpot-wpc` распространяется по MIT и работает внутри основного контейнера с гостевым Chromium.

Исходный код и сведения о лицензиях сторонних компонентов доступны в соответствующих официальных репозиториях и образах.
